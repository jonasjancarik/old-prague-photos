# Náhledový obrázek pro sdílení

Obrázek `/og.png` používá skutečný archivní snímek Kaprovy ulice. Zdroj:
[Archiv hlavního města Prahy, signatura VIII 907](https://katalog.ahmp.cz/pragapublica/permalink?xid=A14CE1A8B67611DF820F00166F1163D4),
XID `A14CE1A8B67611DF820F00166F1163D4`. Katalog uvádí autora
„Eckert-ateliér“ a datum 26. 8. 1906. Obraz byl sestaven z lokálně uložených
Zoomify dlaždic; archivní vodoznaky zůstaly zachované. Vedle něj je název webu.

Před veřejným zveřejněním ověřit podmínky užití u Archivu hlavního města Prahy
a případně získat souhlas pro propagační náhledový obrázek.
